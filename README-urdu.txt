حق الیقین انسٹیٹیوٹ — GitHub Pages پر لگانے کا طریقہ

1. github.com پر مفت اکاؤنٹ بنائیں، پھر New repository دبائیں۔ نام مثلاً haqqul-yaqeen رکھیں، Public چنیں، Create دبائیں۔
2. "uploading an existing file" پر کلک کریں۔ اس فولڈر کی تمام فائلیں اور q فولڈر (g1.json سے g9.json) کھینچ کر ڈالیں۔ index.html اور content.json اوپر ہوں۔ Commit changes دبائیں۔
   (اگر فولڈر کھینچنے سے q نہ جائے تو پہلے اوپر والی فائلیں، پھر Add file > Upload files میں q کی فائلیں ڈالیں، اور نام "q/g1.json" والی ترتیب میں رکھنے کے لیے فولڈر ہی کھینچیں۔)
3. ریپوزٹری میں Settings > Pages جائیں۔ Source میں "Deploy from a branch"، Branch میں main اور / (root) چنیں، Save دبائیں۔
4. ایک دو منٹ بعد اوپر لنک آ جائے گا: https://آپکا-نام.github.io/haqqul-yaqeen/ — یہ سب کے لیے کھلتا ہے۔

بعد میں مواد بدلنا (بغیر Claude کے):
- ویب سائٹ کے نیچے "ایڈمن" پر جائیں، پاس ورڈ ڈالیں۔
- GitHub سیٹنگ ٹیب میں اپنا یوزر نیم، ریپوزٹری کا نام اور Personal access token (Contents: Read and write) ایک بار ڈالیں۔
- لیکچر، قصے، مضامین، کوئز یا نیا سیکشن شامل کریں اور "ویب سائٹ پر شائع کریں" دبائیں۔ ایک دو منٹ میں سب کو نظر آئے گا۔
- ٹوکن کے بغیر کوئی دوسرا شخص تبدیلی محفوظ نہیں کر سکتا۔
